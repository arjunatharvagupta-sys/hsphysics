Formula Sheet

Full-year reference. Know when each applies, not only the symbols.

Kinematics

v = v₀ + at x = x₀ + v₀t + ½at² v² = v₀² + 2aΔx x = x₀ + ½(v₀+v)t

Dynamics

ΣF = ma W = mg fₛ ≤ μₛN    fₖ = μₖN F_s = −kx

Energy

W = Fd cosθ KE = ½mv² PE_g = mgh    PE_s = ½kx² W_net = ΔKE P = Fv = W/t

Momentum

p = mv J = FΔt = Δp Σpᵢ = Σp_f (isolated)

Circular & Gravity

a_c = v²/r F_c = mv²/r F_g = Gm₁m₂/r² v_orbit = √(GM/r) T² = (4π²/GM)r³ v_escape = √(2GM/R)

Rotation

ω = ω₀ + αt τ = rF sinθ Στ = Iα KE_rot = ½Iω² L = Iω I = I_cm + Md²

Oscillations

T = 2π√(m/k) T = 2π√(L/g) E = ½kA² v_max = Aω

Fluids

P = P₀ + ρgh F_b = ρVg A₁v₁ = A₂v₂ P + ½ρv² + ρgh = const

Thermodynamics

PV = nRT ΔU = Q − W Q = mcΔT η_Carnot = 1 − T_C/T_H

Waves & Sound

v = fλ v = √(T/μ) f_n = nv/(2L) (string) β = 10 log(I/I₀) f' = f(v±v_o)/(v±v_s)

Electrostatics

F = k|q₁q₂|/r² E = kq/r² V = kq/r U = kq₁q₂/r C = Q/V = κε₀A/d U_cap = ½CV²

Circuits

V = IR R = ρL/A P = IV = I²R = V²/R V_terminal = ε − Ir

Magnetism

F = qvB sinθ F = ILB sinθ r = mv/(qB) ε = −dΦ_B/dt B_wire = μ₀I/(2πr) B_solenoid = μ₀nI

Optics

1/f = 1/dₒ + 1/dᵢ m = −dᵢ/dₒ n₁ sinθ₁ = n₂ sinθ₂ d sinθ = mλ

Modern

E = hf = hc/λ K_max = hf − φ λ = h/p E_n = −13.6 eV/n² γ = 1/√(1−v²/c²) E = mc²
