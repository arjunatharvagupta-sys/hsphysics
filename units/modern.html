Modern Physics

Relativity, photons, photoelectric effect, wave–particle duality, and the Bohr atom.

Special Relativity

γ = 1/√(1−v²/c²) Δt = γ Δt₀ E = mc²

Tip

Proper time Δt₀ is the time in the frame where the clock is at rest. Moving clocks always run slow as seen from the lab.

Photons and Photoelectric Effect

E = hf = hc/λ K_max = hf − φ

Wave-theory failure

Classical waves predicted that brighter light (more intensity) should always free electrons eventually. Experiment: only frequency matters for the threshold.

Wave–Particle Duality

λ = h/p

Bohr Model and Spectra

E_n = −13.6 eV / n² ΔE = hf

Example

Hydrogen n = 2 → n = 1: ΔE = 10.2 eV. Photon wavelength λ = hc/ΔE ≈ 122 nm (UV, Lyman series).
